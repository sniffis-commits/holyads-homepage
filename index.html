Billing engine

CPC, CPM and CPA bidding, double-entry ledger, deposits via Stripe or PayPal, refunds, invoices and budget pacing.

Async JS tags, iframes, REST API for apps, smart links, SVG/PNG QR codes, VAST/VMAP video, email and CMS snippets.

Getting started

Up and running in minutes

No Composer, no Node build step. PHP 8.1+, PDO and a web server are all it takes.

1

Clone

Get the source from the private GitHub repository.

2

Install

php setup.php creates the schema and loads seeded POC data.

3

Run

run.bat on Windows or ./run.sh on Linux.

4

Explore

Log in as admin or demo advertiser — credentials are in the README.
